# Privacy adapters — reserved interface, not a shipped package

This legacy directory does **not** expose an audited or deployed confidentiality adapter. StealthBridge requires **separate verification** for private commercial amounts and for sender–recipient relationship privacy.

Research and proof gates live in [privacy integration documentation](../../docs/WALLET-SMART-ACCOUNT-AND-PRIVACY-INTEGRATION.md), [independent reproduction](../../docs/INDEPENDENT-PRIVACY-REPRODUCTION-29-31.md) and [security gates](../../docs/PRIVACY-RELEASE-GATES.md). The current typed consumer SDK is maintained in [stealthbridge-sdk](https://github.com/stealthbridge-labs/stealthbridge-sdk).

Do not infer financial permission from this placeholder. No customer witnesses, private keys or note plaintext should be sent to backend telemetry.
