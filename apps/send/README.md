# Send application placeholder

This directory is **legacy monorepo scaffolding**, not a deployed consumer app. The actual signed-in Send journey lives in [stealthbridge-frontend](https://github.com/stealthbridge-labs/stealthbridge-frontend/tree/main/src/app/app/send).

The product can browse configured Testnet corridors, check a public recipient with consent and prepare a browser-local transfer review. The frontend cannot authorize or execute value transfers, confidentiality proofs or fiat payouts. All new customer journey work belongs in the frontend repository.

See [product structure and trust boundaries](https://github.com/stealthbridge-labs/stealthbridge-frontend/blob/main/docs/PRODUCT-ARCHITECTURE-AND-JOURNEYS.md).
