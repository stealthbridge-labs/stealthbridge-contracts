# Business application placeholder

This directory is **legacy monorepo scaffolding**, not a running business app. The actual authenticated StealthBridge Business workspace is in [stealthbridge-frontend](https://github.com/stealthbridge-labs/stealthbridge-frontend/tree/main/src/app/app/business); its signed-in backend is [stealthbridge-backend](https://github.com/stealthbridge-labs/stealthbridge-backend).

Customers can register pending business applications, inspect actual memberships and plan individual/batch drafts. No business verification, settlement or payout is enabled. New UI work belongs in the frontend repository; do not add a second application here.

See the [current product architecture](https://github.com/stealthbridge-labs/stealthbridge-frontend/blob/main/docs/PRODUCT-ARCHITECTURE-AND-JOURNEYS.md).
