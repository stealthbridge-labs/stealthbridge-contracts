# Roadmap — Engineering Milestones, Not Deadlines

**Now: Sprint 0 — foundation**
Four repositories, accountable read-only API, static settlement states, primitive registry, UI preview, SDK contract, research documentation. Identify and fix build/test issues before external funding.

**Milestone A — Stellar cryptographic feasibility**
Vanilla official Confidential Tokens transfer tested on testnet; SPP deposit-transfer-withdraw tested separately; disclosure/custody/composability reports with tx evidence.

**Milestone B — single business demo corridor**
Nigeria–Kenya demo assets and fictional rates; partner role/tenant model, authorized quote, signed transfer, chain indexer, reconciliation without real fiat. Contract and SDK versioned release tags.

**Milestone C — consumer private rail**
Browser proof, shielded note backup/recovery, funding and unshielding, simulated local payout, usability/security research on metadata exposure.

**Milestone D — stablecoin issuer and multi-provider platform**
Issuer-managed confidential asset evaluation, policy and auditor scopes, multi-tenant B2B APIs, reconciliation and risk governance, scale benchmarks.

**Milestone E — open source + Drips**
License decision, security contacts, branch protections, CONTRIBUTING, tested CI, small contributor issues, public technical design review, project funding registration only with explicit organizational approval.

All target milestones are contingent on testnet compatibility and security outcomes. No deadlines, partner agreements or real transfer volume are promised.
