# Security policy (testnet research phase)

Do not use with real funds. Do not include private keys, wallet seeds, spend notes, sensitive KYC data, provider secrets, or zero-knowledge witnesses in issues, code, screenshots or logs.

Security issues: use GitHub private vulnerability reporting once enabled in repository settings. Until then, avoid posting exploit details publicly; set up a dedicated security contact before inviting third-party testing.

Nothing here has been audited or certified for production.
